# chesswhisper — live demo

Analyze chess games with Stockfish and get a coaching report: accuracy and
ACPL, mistakes by game phase, time-control and opponent breakdowns, error
patterns, a move-by-move game viewer and puzzles made from your own mistakes.

Sign in as **demo** / **demo-password** to browse analyses that are already
there, or create an account and analyze your own games from Lichess or
chess.com (up to 10 per analysis in the demo). Data resets whenever the Space
restarts, and LLM commentary is off here.

Source, documentation and a self-hosting guide:
https://github.com/Caglar-Coban/chesswhisper

The demo account's games are public Lichess games; Lichess game data is
released under CC0.
